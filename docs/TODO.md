# Backlog

Ideas and requests that don't fit neatly into a `development-plan.md` phase yet, or are worth remembering before they're scheduled into one. Check here alongside the phased plan when starting new work.

- **Guided tour through the app** — an interactive walkthrough (e.g. highlighted tooltips/coach-marks) showing the user the main functions on first launch or on demand. Likely belongs with Phase 6's onboarding work, but could also stand alone as a "Help > Take a tour" entry point.
- **Exercise descriptions for testing** — add descriptions to exercises in the current seed database for testing purposes: some text, maybe open-source/access images, and links to MuscleWiki or YouTube for reference.
- **Add exercises to a plan straight from the Exercise Library** — currently the only way to add an exercise to a plan is via spreadsheet/JSON import or the native plan-builder (not yet built, per Phase 1's outstanding items). Add a way to add directly from the library: tapping an exercise could show its detail with an "Add to plan" button, or a long-press on an exercise in the list could bring up a context menu with an "Add to plan" option.
- **Bug: newly-scheduled sessions don't show on the calendar** — assigning a date to a plan session (via "Assign date" on the plan detail screen) doesn't make it appear on the Calendar tab. Needs investigation - `CalendarDao`/`getSessionsInRange` and the calendar screen's provider should be checked for a stale-cache or query issue (possibly the same class of one-shot-`FutureProvider`-doesn't-notice-writes gotcha documented in CLAUDE.md, or a genuine query bug).
- **Show the selected day's sessions below the calendar** — tapping a date on the Calendar tab should show that day's scheduled session(s) below the calendar grid; tapping one of those should navigate to execution mode so the user can start that session directly from the calendar.
- **"Move to today" prompt when starting a session scheduled for a different day** — e.g. tapping "Start" on tomorrow's session should prompt "This is scheduled for tomorrow - move it to today and start now?" with Confirm/Cancel, so a user can start an out-of-order session without manually re-assigning its date first.
